## Decision update — PCC-ACE-002 (2026-11-26)

The Principal Architect approved deterministic, source-anchored cross-segment reconciliation with conditions. Existing proposal de-duplication and identity review can be used to merge segment outputs without losing provenance; this is not described as AI global semantic understanding. Separate global semantic synthesis and additional model calls are deferred. Durable checkpoints may use the existing IndexedDB database in a separate `analysis-checkpoints` object store, logically separate from canonical projects and manuscripts. Checkpoints may contain validated derived proposals, source digest/identity metadata, immutable plan and policy identity, provider/model/reasoning configuration, segment states, attempt budget, and coverage. They must never contain credentials, source manuscript text, or raw user instructions. Restart requires source, plan, evidence, provider/account eligibility and policy revalidation plus explicit user action. Completed verified segments may be reused. In-flight requests become uncertain and are never automatically replayed; consumed budget is not reset. Checkpoints are bounded, deletable, schema-validated, and storage failure must prevent a new upstream call when reservation cannot be persisted. No checkpoint can mutate canonical narrative state. The Architect approved this based on the implementation description and stated that they had not independently reviewed the implementation.
