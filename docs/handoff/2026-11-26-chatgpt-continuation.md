## 3. What PCC is — product and engineering invariants

PCC started as a small Google AI Studio creative co-creator and evolved into a writer-focused narrative workspace, not a generic chatbot, Word clone, video generator or project-management dashboard. Video was deliberately removed; Story and Image modes remain. Core work: begin from an idea or existing manuscript, write and organize optional chapters/scenes, inspect character/entity relationships and beliefs, manage Story Bible, trace narrative evidence, identify continuity issues, review AI suggestions and creative opportunities, produce story/image artifacts, and preserve/restore projects.

Four separate data authorities: (1) immutable original source and source identity/digest; (2) editable Working Manuscript with version lineage; (3) accepted narrative model/canon with stable IDs; (4) immutable generated artifacts. Source statements, character beliefs, hypotheses, proposed claims and accepted canon are not interchangeable. Narrative order is not chronological order and correlation does not establish causation. Evidence includes exact spans/source and revision, with explicit partial/ambiguous/unsupported scope.

Write, Plan and Review are stable workspace modes; Projects and Import Story are explicit commands, not saved workspace modes. Write-first default for new/first projects; returning restores valid prior stable mode. Optional chapters/scenes; AI never required for manual writing. Focus mode uses the same editor authority, retains context/selection/scroll when safe. Plan includes actual graph and Graph/Table/Ego/Family, Story Bible, Timeline, Mind Map, Ideas/creative opportunities, decision inbox, prompt, output/gallery. Family view uses verified kinship semantics, accessible text/table alternative; no independent graph state. Review separates readiness reminders from real diagnostics, offers local and optional semantic checks, text/model sync proposals, evidence, issue lifecycle and versioned diffs. An AI suggestion is not acceptance; no stale or invalid output mutates canon, manuscript or artifacts.

Import: faithful source-only path without AI, optional analysis, separate Stage 2 enhancement review, new project or explicit append target, duplicate/identity resolution, revision guards, partial coverage and cancellation. Supported parser behavior for text, Markdown, DOCX, PDF and EPUB is bounded; preserve originals and evidence; do not imply complete extraction of unsupported structures. Q06 tested staged source and in-flight mocked extraction cancellation with unchanged IndexedDB digest, revision and manuscript; mock late result was empty, not every possible payload. Backup/recovery: JSON, text/Markdown/DOCX, ZIP all-project archive, checksum and safe extraction, verified safety checkpoint for replacement, copy restore default, partial restore retry only remaining suffix; external folder availability depends on runtime; retention explicit.

IndexedDB remains durable authority, localStorage a cache/preference/fallback with explicit failure semantics. Preserve one transaction/CAS read-check-write seam, exact base/revision/manuscript guards, canonical operation fingerprint/idempotent intent replay and stored-state reconciliation, tombstones, hydration/reload/write gate, serial save queue, undo/redo revision references, draft failure/retry. No second global state store or repository rewrite. Turkish Unicode, selection UTF-16, IME, keyboard/focus and responsive behavior are contracts. Never sacrifice safety branches to make CodeScene metrics look good.

Existing AI security: server-side Gemini, strict Zod schemas, 8K legacy prompt cap where applicable, bounded token counting, per-operation and aggregate resource budgets, max output tokens when transport supports it, bounded retry/timeouts, AI Ticket Authority and stale-response suppression, explicit approval. Existing budget counters process-local; operation fingerprints non-cryptographic; document, don't conflate with cryptographic security or global spending guarantee. Live AI quality not yet established by mocked tests.
