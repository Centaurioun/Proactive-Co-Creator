## B3 — Creative Studio: discover, focus, card lifecycle (CE-01–04, CE-07, UI-NEW/GS-04, IR-03)
Four meaningful modes: Discover with AI, Guided Exploration, Focused Development, Story Lab (first safe scenario exploration/idea branch, advanced simulations/alternative projects WP05). Shared collaboration/session engine rather than four duplicated workflows. Provide discover scope, custom goal, concrete examples and source context using E1 local lookup/Context Inspector; no automatic embeddings or AI. Reuse existing opportunities endpoint where appropriate and extend validated action-specific contracts as necessary. Opportunity results become persistent creative idea versions, distinguish inspiration/hypothesis vs current fact vs actual patch. Existing opportunities and prior saved records remain visible/reachable; no destructive migration. Card actions must actually work:
- Preview idea and concrete proposal separately; Edit idea text/direction manually distinct from editing exact patch.
- Regenerate selected card only, optional guidance, preserve prior version and other cards; new alternative not silent replacement.
- Develop Further preserves core concept, creates linked version; suggested directions multi-select (e.g. more mystery/science/complexity/originality/drama/surprise), custom direction, Surprise Me; Suggest More Directions appends distinct options without losing current selection.
- Custom text input exposes two distinct actions: Suggest Directions (return directions only based on cue), Generate Idea (return concrete idea from cue). Develop with Selected Directions explicitly initiates action. No AI call on selection, tab switch, typing or resume.
- Save for Later/bookmark, Dismiss recoverable, restore, compare versions, combine selected ideas/directions (explicit request), Explain Differently, Challenge This Idea. Multi-selection enables save/dismiss/combine/stage review, never blind batch apply.
- Saved Ideas/Creative Collection, Exploration History, Active Sessions, Selected Changes accessible, searchable/taggable local library within project with appropriate source/session links; no cross-project automatic access. Keep source provenance and stale status, return/resume context.
- Direct review and apply from card/session without redundant Accept -> Send to Change Review sequence; if not yet concrete patch, stage idea and request explicit generation/review. Actual E3 preview shows exact change, editable selected patch, no auto-adoption. Save draft/continue exploration always available. Alternative Project button only when independent safe clone capability actually exists; otherwise clear later WP05 availability, don't clone unsafely. No automatic project switch.
