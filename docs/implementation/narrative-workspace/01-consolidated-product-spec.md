# Proactive Co-Creator — consolidated product specification vNext

Date 2026-11-24. Product scope approved by owner in rounds 4 and 5; engineering defaults delegated; this specification consolidates, not erases, the discovery archive. Source records: docs/product-design/narrative-import/ (links below). Implementation is staged via Google AI Studio first, independent Codex/ChatGPT review afterward. No new product implementation in the documentation commit. No mandatory new Figma design gate before preview implementation: earlier IA/Figma intent is retained as a design/validation guide, owner now prioritizes seeing working AI Studio previews. Follow Stage0 usability/accessibility evidence; if Figma used later, synchronize with actual implemented UI, not a parallel incompatible design.

## 1 Product goal and invariants
A writer-focused, local-first AI narrative workspace, not just prompt generator. Start from an idea, or reconstruct existing story into an editable manuscript and structured narrative project; maintain fidelity, author authority and traceability. All native and imported projects use same data and operations. Keep existing Story/Image modes, idea/prompt/notes, clarification, graph, relationship & attribute editors, Story Bible, decisions, NL batch preview/apply, review/polish, generation, gallery, project switch/create/delete, undo/redo/revision history, old JSON import/export, errors/recovery and keyboard support. Do not remove a feature to make new UI easier. No mandatory chapter setup, no mandatory AI use, no new cloud/team/provider migration, no Word clone, no video feature. Existing Gemini server boundary remains; AI requests explicit by default, never leak keys or unpublished text. Old projects and backups load losslessly; migration tested, no silent data deletion; no fabricated citations or fake passing tests.

## 2 Information architecture
Project hub: Start from Idea, Import & Analyze Story, Export Content, Backup & Restore; global Settings independent of project backup. Rename native JSON import to Restore Project Backup / Restore from JSON, keep file/paste and compatibility. Separate Revision History. Workspace logical modes Write / Plan / Review, not mandatory wizard; exact nav responsive. Write: manuscript outline, editor, contextual inspection and focus mode, artifact adoption; Plan: graph/Bible/decisions and views; Review: Diagnostics, Opportunities, Evidence & Audit, History, relevant output links. Existing output gallery discoverable, not hidden behind new mandatory manuscript. Minimize tabs: contextual links, switcher, commands, drawers; desktop full writing width, mobile no clipped actions, accessible focus/order, tables for graph, labels/icons not color alone. Preserve current Stage0 journeys. Newly unfinished controls show “Planned for Phase X” or disabled with reason, not fake success or simulated AI labeled real. Demo sample explicit, isolated from real user projects; don't replace current workspace with mock-only app.

## 3 Four data authorities
Original source immutable (retain original file bytes by default within safe limits, opt-out extracted-only disclosed; paste source text); Working Manuscript editable primary narrative prose; canonical model approved semantic facts/decisions; generated artifacts immutable historical generation output (adopt explicitly). Source proves original wording; working text proves current wording; graph expresses accepted author intent. Conflicts may be intentional or unreviewed, not unconditional errors. Shared registry records evidence, rationale (short explainable reason, not hidden chain of thought), audit changes and issues across all domains. Stable project/entity/relation/source/manuscript/chapter/scene/block/claim/issue IDs; source version and digest. No name-only identity merging, no second graph or duplicate truth store. Chapter headings only when actual/approved; document order != chronology; character belief/quote vs world fact distinct. Revisions reference immutable versions; don't duplicate whole novels per keystroke. Commit via current storage authority, atomic or verified recoverable protocol with CAS, stale guard and undo/redo. Backups and restore include all referenced records or explicitly label incomplete. Prior JSON schema3 compatibility, migration backup and validation mandatory. Unknown newer schema read-only/reject safely, never overwrite. Never fake “Saved” before durable success. See architecture contract.

## 4 Writing Studio
One primary editable manuscript per project, optional chapters/scenes/stable blocks. Plain story without chapter structure allowed. Add, rename, reorder, split, merge, delete with preview where destructive; preserve exact ordering/text and ID lineage. Optional synopsis, characters, location, chronology, POV, purpose, Draft/Revised/Final author labels. Focus mode, keyboard, Unicode/IME, basic headings/paragraphs/emphasis/quote/list as supported, safe paste, search and word count, save status. Editor implementation selected via serialization/IME/accessibility/performance/license/security proof, not a dependency mandate. Manual writing offline. Generate story/image behavior preserved. Adopt full/selected artifact to append/new scene/replace with preview, provenance retained; original artifact unchanged. AI writing selection rewrite/clarity/expand/shorten/continue/dialogue/alternatives/custom instructions, exact scope and before/after, accept/none, keep alternate. No silent auto insert or change outside selected scope.

## 5 Intelligent Import
Paste/TXT/MD/DOCX first, PDF text/EPUB additional phase; format scope and limitations explicit, OCR/ODT/RTF/Fountain/FDX optional later backlog, no claim of unsupported file formats. File selection local parsing and preview only; explicit Analyze starts server AI. Preserve original content, real structural labels, source blocks/offsets; inspect decompressed size, malformed files, unsupported formatting/tracked changes/footnotes/tables policy; no external URL fetch/active content. Configure Faithful (default) vs Reconstruct & Enhance, independent Full/Selective scope, optional import instructions, user-selected extraction categories, provider/estimated budget disclosure. Faithful extracts only supported facts; no invention, rewrite, auto fix or creative suggestions. Interpretations pending, no forced unknown values. Enhancement first faithful then separate explicitly approved changes. Segment/chunk long input, coverage and retry/cancel, identity/alias resolution and cross-chunk dedupe, extraction of characters, traits, relations, locations, objects, events, themes/style, Story Bible, possible continuity issues. Validate quotes/source anchors programmatically; valid quote does not prove entailment. Show source support, uncertainty, conflict/possible contradiction, before/after enhancements separately. Batch accept eligible facts, reject, defer unresolved or clarify; pending excluded from confirmed generation context. Only explicit Create Project commits, durable success or honest recoverable failure. New project first, safe append to existing project later with preview/revision/CAS, no silent overwrite. Partial analysis not falsely complete; failed coverage blocked unless explicit incomplete import with visible unprocessed scope. No AI before Analyze or project mutation before Create.

## 6 Token-aware context
Remove arbitrary user-facing 8000-character restriction only when replacement guards installed for each affected operation. Long local writing/source preserved. Estimate/count model-specific input+output/reasoning/instructions/schema budgets, server body limits, bounded request/chunk sizes, total job budget/calls, cancellation, retry/time/concurrency caps, cost/usage distinction. Verify current provider capability at implementation time; no invented model capacities/prices/free quota. No globally unbounded Express body, no silent truncation, no repeated whole manuscript for small edits. Select confirmed relevant context and actual source anchors, show scope/coverage/omitted parts. Untrusted manuscript is data not instructions; prompt injection isolation and schema validation, no client Gemini keys. Manual explicit analysis; optional user-enabled automatic semantic check while app open only with budget/consent, no background promises.

## 7 Evidence, rationale, audit and diagnostics
Every imported substantive canonical claim, issue and applied AI change has source/project-revision evidence, stable targets and concise reason; reuse spans, no fabricated chapter/line. Source viewer actual excerpt/location, provenance (explicit/inferred/belief/reported/ambiguous/AI suggested/user authored), approval independent of evidence kind, freshness independent of disposition. Persistent record accessible in graph/scene/Bible/checks and Evidence & Audit; same data deterministic JSON/Markdown reports, filtered/full options. Audit actor/action/time/base+result revision/before-after/reason/source/target and compensating undo event, no raw internal model reasoning, no tamper-proof claim.
Narrative Diagnostics covers all projects and changes: automatic deterministic checks, explicit Quick/Focused/Recent Changes/Full AI review with scope/time/revision/coverage/freshness, no AI every keystroke. Separate readiness from problems, certainty from severity, intentional ambiguity from contradiction. Persistent issue lifecycle Open, Deferred, Needs Clarification, Proposed Fix, Resolved, Dismissed/Intentional. Defer keeps unresolved; dismiss reason retained, re-open meaningful changed evidence, stable issue fingerprint/dedupe, never close just because not returned in partial run. Source native projects use authored fields/revision or artifact anchors, not fictional source. Targeted dependency index and bounded visited-set impact analysis, no automatic rewrite loops. Text→model analysis proposes explicit additions/edits; absent mention not delete. Model→text proposes exact scoped patches, no blind global replace; temporal scope/alias/unreliable narration respected. Auto mark affected claims/issues stale, local recheck; author approves changes, atomic text+model+audit, revalidate; graph-only repair not prose repair. Up to three meaningful AI alternatives, none/clarify/retry with guidance and bounded cost; not force exactly three; red/green strike/add accessible in-app review, before/after and impacted targets, source unchanged. Revert safe transaction or revision checkpoint; stale proposal requires re-preview. No independent contradictory registries.

## 8 Creative opportunities and visualization
Explore Improvements separate from problems: optional character arc/motivation/relationship/plot/conflict/stakes/pacing/themes/foreshadow/setup-payoff/world/style/voice ideas, user goal/scope, benefits/tradeoffs/assumptions, evidence, save/defer/dismiss/alternatives/stage proposal; no auto insertion, no artistic quality score. Faithful import never invokes this. Graph remains existing view; Character Relationship Map, family-only verified kinship layout/filter, Narrative Mind Map, Timeline (story chronology vs narration order) projections of same canonical IDs, shared warning icon/text/count/color overlays, issue detail navigation and accessible table, pending vs confirmed, filters by scope/time. Auto update on committed edits/restore/undo without AI; preserve layout if possible; no forced tree for cyclic kinship, no infer causality from proximity, no duplicate graph authority; large graph filtering/benchmarks.

## 9 Export, backup, restore
Autosave != revision history != managed recovery snapshot != portable backup export. Internal Backup Vault separate recoverable records inside browser (not device disaster protection); Create Backup without download, list/verify/restore/export/delete/pin and status. Optional external folder via supported File System Access API with explicit user permission, visible folder suggestion Documents/Proactive-Co-Creator/Backups; no arbitrary home/remote disk or background access. Fallback download; permission revoked/quota/partial write errors honest; keep last verified copy, configurable retention, dedupe, opt-in auto while running, safety checkpoint before destructive replace/migration/bulk change as applicable. Current/all-project scope, separate non-secret app settings optional, no API keys. Restore schema/revision/size/source/completeness preview, default collision restore as copy with all refs remapped, explicit replace with safety checkpoint and tests, no silent overwrite. Portable complete backup includes source bytes as promised, working revisions, graph, artifacts, decisions, issues/evidence/audit/history/version refs/checksum manifest; retain old JSON. ZIP safety/size/path validation; browser vault loss warning. Export Center selected original/extracted/working/generated, chapter/scene/full, Story Bible, prompt, evidence/issues/audit reports JSON/MD, TXT/MD/DOCX supported formatting, optional ZIP selected content with manifest. Content bundle != restorable backup. Safe file names project slug_shortID_kind_revision_UTCtimestamp.ext, actual extension/MIME, display full title/date/time locally. Source/backup privacy and explicit deletion/retention policy, no silent purge.

## 10 Quality and delivery
Five substantial phases defined in README and phase documents; all agreed scope mapped in coverage matrix. Technical preflight and phase gates common. New features may be incomplete during preview (explicitly disabled/deferred), but existing data safety, working app shell and report honesty non-negotiable. No production release/merge until qualification. Real-model quality is separate from key-free mocked integration tests; hand-annotated Turkish/English fixtures with grounding/identity/contradiction/coverage, no invented statistics. Test actual installed dependencies; preserve 106+ baseline tests (count may increase), existing E2E A–I, Stage0 J01–12 where affected; append new journeys, accessibility target WCAG2.2AA not certification; performance baseline comparison and real hosted preview. Design-level six-cycle review each phase; independent review final.
